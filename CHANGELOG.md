# Что нового

Сюда перед каждым релизом добавляется раздел `## vX.Y.Z`. Текст раздела
попадает в описание релиза на GitHub, к нему CI сам дописывает инструкцию
по установке (см. `packaging/release/notes.sh`).

## v0.1.1

### Новое

- ✏️ **Свои фразы для голосовых команд.** Любую команду можно дополнить своими фразами или заменить встроенные: полем `commands` в конфиге или в веб-панели, в новом разделе «Голосовые команды». Выбор в панели сохраняется в `state.json` и важнее конфига; пустое поле возвращает фразы из конфига. Без поля `commands` всё работает как раньше. Пример есть в README, в разделе «Свои фразы для команд».
- 🗣️ **«Яндекс» как слово-обращение.** Команды понимаются и после «Яндекс, …», а не только после «Алиса, …».
- 🪟 **Установщик для Windows.** `install.ps1` делает то же, что `install.sh`: скачивает релиз, сверяет `SHA256SUMS`, по SSH ставит или обновляет плагин. Работает в Windows PowerShell 5.1 и PowerShell 7, параметры `-Chat`, `-Version`, `-Package`, `-Port`.

### Исправлено

- 🧠 Веб-панель больше не ломается, когда общая память пуста: раньше она прорисовывалась наполовину, и поля промпта и команд оставались пустыми.

### Документация

- 📖 README переписан: установка и первый запуск в начале, однострочники для macOS, Linux и Windows, подробности (все команды, свои фразы, память, поиск, параметры установщика) свёрнуты под спойлеры.
