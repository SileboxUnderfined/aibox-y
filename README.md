# AIBox для Яндекс Станции

> Неофициальный проект энтузиаста. Не связан с ООО «Яндекс», не одобрен и не поддерживается им. Подробности в разделе [Правовая информация](#правовая-информация).

Чаты с нейросетями (DeepSeek, Claude, OpenAI, OpenRouter) прямо с колонки, по командам Алисы. Ключи API хранятся на самой Станции, запросы к провайдерам идут с неё.

| Команда | Что делает |
| --- | --- |
| «Алиса, новый чат» / «новый чат *название*» | Создаёт и сохраняет чат. Без названия имя придумывается по первому вопросу |
| «Алиса, спроси *вопрос*» / «спроси *модель* *вопрос*» | Сразу задаёт вопрос модели по умолчанию или названной («спроси клода …»), в новом сохраняемом чате; дальше разговор продолжается без команд. Также «спроси нейросеть …», «задай вопрос нейросети …», «спроси ИИ …» |
| «Алиса, продолжить чат *название*» | Ищет сохранённый чат по названию (терпимо к окончаниям и ошибкам распознавания) |
| «Алиса, поговорить» | Временный чат, не сохраняется |
| «Алиса, забудь чат *название*» | Удаляет чат (файл уходит в `chats/trash`) |
| «Алиса, список чатов» | Называет сохранённые чаты |
| «хватит», «закрой чат» | Выход из чата; также через 10 минут тишины |
| «Алиса, переключись на клод» / «выбери модель дипсик» | Выбирает модель по названию или псевдониму из `providers` |
| «Алиса, какая модель» | Называет текущую модель и список доступных |
| «Алиса, системный промпт *текст*» / «новая роль *текст*» | Добавляет свои указания к системному промпту |
| «Алиса, какой системный промпт» / «сбрось системный промпт» | Показывает или убирает свои указания |
| «Алиса, выключи интернет» / «включи интернет» | Запрещает или разрешает нейросетям искать в интернете |

Яндекс по умолчанию маскирует мат при распознавании («х**»). Пока чат открыт, AIBox просит распознавание без маски (флаг `DisableAntimat` в запросе прошивки); обычные запросы к Алисе не меняются. Отключается `"keep_antimat": true` в конфиге.

Пока чат открыт, Алиса слушает дальше без слова «Алиса», и всё сказанное уходит в нейросеть. Вне чата все запросы идут в Яндекс без изменений.

## Как это работает

Прошивка Станции общается с облаком Алисы по WebSocket (`uniproxy`). AIBox ставится между ними на `127.0.0.1:8443`: в `quasar.cfg` адрес `uniProxyUrl` меняется на `ws://127.0.0.1:8443/uni.ws`. Распознавание речи и синтез голоса остаются у Яндекса, поэтому ответы нейросети звучат голосом Алисы. Протокольная часть взята из [quasar-bridge](https://github.com/skrashevich/quasar-bridge).

## Установка

Нужны root и SSH на колонке, aarch64-ядро и [YAM](https://hackalice.me/recipes/yam/). Проверено на Станции Мини 2 (прошивка 0.372.1.8).

Готовый архив `aibox-<версия>-linux-arm64.tar.gz` и `SHA256SUMS` лежат в [Releases](https://github.com/SileboxUnderfined/aibox-y/releases); внутри та же папка `aibox-pkg`. Новый релиз собирается сам при пуше тега `v*` (например, `git tag v0.2.0 && git push origin v0.2.0`), тег с дефисом (`v0.2.0-rc1`) публикуется как пре-релиз.

Или собрать самому:

```bash
make package   # собирает dist/aibox-pkg
tar czf - -C dist aibox-pkg | ssh -p 2222 root@<ip> 'cd /tmp && gzip -dc | tar xf - && mv aibox-pkg /data/quazar/yam/data/plugins/aibox'
```

На колонке:

1. `curl -X POST http://127.0.0.1:8099/api/plugins/aibox/toggle` и `.../service/enable`, `.../service/start` (или через веб-интерфейс YAM).
2. Ключи в `/data/opt/aibox/secrets.env` (права 600), провайдер и режим в `/data/opt/aibox/config.json`.
3. `sh /data/quazar/yam/data/plugins/aibox/aiboxctl.sh apply` переключает Алису на AIBox и перезапускает quasar. `rollback` возвращает как было, `status` показывает состояние.

Выбранная модель и свой промпт сохраняются в `/data/opt/aibox/state.json` и переживают перезапуск. Модели задаются в `providers`: у каждой есть `title` и `aliases`, по которым её узнают голосом; можно добавить несколько моделей одного провайдера. Базовый промпт с правилами для озвучки задаётся полем `system_prompt` (пустое значение = встроенный), голосовой промпт добавляется к нему.

## Интернет

Нейросеть может искать в интернете, когда вопросу нужны свежие данные: новости, погода, курсы, расписания. Как в приложении ChatGPT, модель сама решает, что ей нужен поиск: она вызывает инструмент `web_search` (tool calling), AIBox передаёт запрос поисковику, а ответ модель пересказывает голосом. Так ищет любая модель с вызовом функций, включая DeepSeek.

Поисковики выбираются в веб-панели по порядку, до трёх: если первый не ответил за 20 секунд или с ошибкой, спрашивается следующий.

- **Поисковая модель** — любая модель со своим поиском: Perplexity Sonar (свой API `https://api.perplexity.ai` или `perplexity/sonar` в OpenRouter, ищет на каждый запрос), модели OpenRouter с `:online`, OpenAI (Responses API с `web_search`), Claude (инструмент `web_search`), OpenRouter (плагин `web`). Она получает запрос и излагает найденные факты в нескольких предложениях.
- **Свой API только для поиска** — при добавлении своего API в панели отметьте «Только для поиска в интернете». Такой провайдер не отвечает в чатах и не выбирается голосом, а только ищет по просьбе основной модели; AIBox спрашивает его как есть, так что модель должна уметь искать сама. Первый такой провайдер сразу становится поисковиком. Поисковиком можно выбрать и любую другую модель.
- **Tavily** — поисковый API, отдаёт 3–4 коротких выдержки. Нужен ключ `TAVILY_API_KEY`. Используется по умолчанию, пока порядок не задан.

Модель со своим поиском может искать и сама, без посредника. Способ выбирается для каждой модели (`auto`, `tool`, `native`, `off`). В режиме `auto` модель ищет через поисковики, если какой-то из них готов, иначе своим поиском, если он у неё есть; Sonar всегда ищет сам. Остальные «OpenAI-совместимые» API, например DeepSeek, своего поиска не имеют. Ссылки и сноски из ответа вырезаются, чтобы их не зачитывать. Поиск включается только в чатах, служебные запросы (название чата) идут без него. Настройки Tavily в конфиге: `"search": {"provider": "tavily", "api_key_env": "TAVILY_API_KEY", "max_results": 4}`.

## Веб-панель

`http://<ip колонки>:8100`, логин любой, пароль в `/data/opt/aibox/web.password` (создаётся при первом запуске). Панель работает в том же процессе AIBox и позволяет выбрать провайдера и конкретную модель (кнопка «Загрузить список» спрашивает модели у провайдера), задать свой промпт и базовые правила, вписать ключи. Там же можно добавить свой API: OpenAI-совместимый (Groq, Together, Mistral, Ollama или LM Studio в локальной сети и т. п.) или Anthropic. Указываются название, адрес до `/v1`, модель, ключ и имена для голоса; такой провайдер хранится в `state.json`, его ключ в `secrets.env` как `AIBOX_KEY_API_N`. Изменения применяются без перезапуска. Отключается полем `web.enabled` в конфиге.

`mode: "observe"` пропускает всё в Яндекс (проверка протокола), `mode: "chat"` включает чаты.

## Риски

Если AIBox не запущен, а адрес переключён, Алиса не отвечает совсем: используйте `aiboxctl.sh rollback`. Обновление прошивки может перезаписать `quasar.cfg` или изменить протокол. Речь по-прежнему обрабатывает Яндекс, а текст вопросов уходит выбранному провайдеру.
