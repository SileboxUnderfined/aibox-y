AIBox

Нейросети в Яндекс Станции. Изменения применяются сразу, без перезапуска.

Модель

Загрузка…

Отмеченный провайдер отвечает в чатах. Ключи хранятся только на колонке и сюда не возвращаются.

Интернет

Когда модели нужно что-то узнать, она сама отправляет запрос поисковику, а ответ пересказывает голосом. Так ищет любая модель, включая DeepSeek.

Поисковики по порядку: если первый не ответил, спросим следующего. Свой API для этого можно добавить ниже с галочкой «Только для поиска». Подойдут модели со своим поиском: Perplexity Sonar (свой API https://api.perplexity.ai или perplexity/sonar в OpenRouter), ChatGPT, Claude, OpenRouter. Или Tavily по ключу:

Голосом: «Алиса, включи интернет» или «выключи интернет».

Добавить свой API

Адрес — до /v1, без /chat/completions. Подойдут Groq, Together, Mistral, Ollama или LM Studio в локальной сети и любые другие с OpenAI-совместимым API. Потом: «Алиса, переключись на …».

Память

Голосом: «Алиса, запомни, что …», «забудь, что …», «что ты обо мне знаешь», «забудь всё обо мне», «выключи память». Факты хранятся на колонке в memory.json и уходят только тому провайдеру, который отвечает.

Ваш промпт

Добавляется к базовым правилам. То же можно сказать голосом: «Алиса, системный промпт …».

Базовые правила

Правила для озвучки: коротко и без разметки. Их стоит менять осторожно.
