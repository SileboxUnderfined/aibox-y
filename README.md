## ✨ Возможности

- 💬 **Сохраняемые чаты** с названиями: начать, продолжить, удалить, послушать список.
- ⚡ **Быстрый вопрос**: «Алиса, спроси клода, …» без открытия чата.
- 🔀 **Любая модель**: DeepSeek, Claude, ChatGPT, OpenRouter, Groq, Ollama в локальной сети; переключение голосом.
- 🌐 **Поиск в интернете**: модель сама ищет свежие новости, погоду и курсы.
- 🧠 **Общая память**: «запомни, что меня зовут Валерий», и это знают все чаты.
- ✋ **Перебивание**: «стоп» обрывает длинный ответ.
- 🖥️ **Веб-панель** в браузере: модели, промпты, ключи, память, свои фразы команд.
- 🔊 **Голос Алисы**: распознавание и синтез остаются у Яндекса, звучит привычно.

## 🚀 Установка

**Что нужно:**

- 🔑 root и SSH на колонке, aarch64-ядро;
- 🧩 менеджер плагинов: [Luna](https://github.com/nyakokitsu/luna) (ставится через новый [YAM 0.2](https://github.com/nyakokitsu/yam): `yam install yam/luna`) или старый YAM 0.1 (`/data/quazar/yam`);
- ✅ проверено на Станции Мини 2 (прошивка 0.372.1.8).

Одна команда на компьютере ставит или обновляет AIBox. Вместо `192.168.88.202` подставьте IP своей колонки.

### 🍎 macOS и 🐧 Linux

```bash
curl -fsSL https://raw.githubusercontent.com/SileboxUnderfined/aibox-y/main/install.sh | sh -s -- --chat 192.168.88.202
```

### 🪟 Windows (PowerShell)

```powershell
& ([scriptblock]::Create((irm https://raw.githubusercontent.com/SileboxUnderfined/aibox-y/main/install.ps1).TrimStart([char]0xFEFF))) -Chat 192.168.88.202
```

Подходят Windows PowerShell 5.1 и PowerShell 7. Нужен встроенный «Клиент OpenSSH» (есть в Windows 10 1809+ и Windows 11; если нет, включите в «Параметры → Система → Дополнительные компоненты»).

Установщик скачивает последний релиз из [Releases](https://github.com/SileboxUnderfined/aibox-y/releases), сверяет `SHA256SUMS`, по SSH кладёт плагин в папку Luna или старого YAM, смотря что запущено на колонке, и запускает его. В Luna он сам включает настройку «Разрешить бинарники плагинов»: без неё AIBox, как любая программа, не запустится. Настройки, ключи и чаты в `/data/opt/aibox` при обновлении сохраняются.

<details>
<summary>⚙️ Параметры установщика</summary>

| install.sh | install.ps1 | Что делает |
| --- | --- | --- |
| `--chat` | `-Chat` | Включает чаты и переключает Алису на AIBox. Без него Алиса продолжает ходить в Яндекс напрямую |
| `--version v0.2.0` | `-Version v0.2.0` | Ставит конкретный релиз вместо последнего |
| `--package dist/aibox-pkg` | `-Package dist\aibox-pkg` | Ставит свою сборку (`make package`): папку или архив `.tar.gz` |
| `--port 2222` | `-Port 2222` | SSH-порт колонки (по умолчанию 2222) |
| `user@ip` | `user@ip` | Другой пользователь вместо `root` |

</details>

<details>
<summary>📦 Без SSH и через новый YAM</summary>

Без SSH можно загрузить `aibox-<версия>-linux-arm64.yap` из релиза через веб-интерфейс Luna или YAM на `:8099` и включить «Разрешить бинарники плагинов». На /data при этом нужно место на две копии плагина.

Через новый YAM (`.yampkg`) AIBox не ставится: Luna пока отклоняет бинарные плагины из YAM.

</details>

> [!WARNING]
> Не запускайте установщик YAM с `--remove-old`: он удаляет `/data/quazar/yam` вместе с AIBox, если тот стоит в старом YAM.

## 🎬 Первый запуск

1. 🖥️ Откройте веб-панель `http://<ip колонки>:8100`. Логин любой, пароль лежит на колонке в `/data/opt/aibox/web.password`.
2. 🔑 Выберите провайдера и впишите ключ API (например, DeepSeek). Изменения применяются сразу, без перезапуска.
3. 🗣️ Скажите **«Алиса, новый чат»** и задайте вопрос. Пока чат открыт, Алиса слушает дальше без слова «Алиса».
4. 👋 Скажите **«хватит»**, чтобы вернуться к обычной Алисе. Чат закроется и сам, через 10 минут тишины.

Если ставили без `--chat`, AIBox работает в режиме наблюдения и всё пропускает в Яндекс; переключить на чаты можно командой `apply` ниже.

<details>
<summary>🛠️ Управление на колонке</summary>

`<папка плагина>` это `/data/quazar/luna/data/plugins/aibox` или `/data/quazar/yam/data/plugins/aibox`.

| Команда | Что делает |
| --- | --- |
| `sh <папка плагина>/aiboxctl.sh rollback` | ↩️ Возвращает Алису в Яндекс напрямую |
| `sh <папка плагина>/aiboxctl.sh apply` | 🔁 Снова переключает Алису на AIBox |
| `sh <папка плагина>/aiboxctl.sh status` | 📊 Показывает состояние |

- Ключи лежат в `/data/opt/aibox/secrets.env` (права 600), провайдер и режим в `/data/opt/aibox/config.json`.
- `mode: "observe"` пропускает всё в Яндекс (проверка протокола), `mode: "chat"` включает чаты.

Выбранная модель, свой промпт и настройки памяти сохраняются в `/data/opt/aibox/state.json` и переживают перезапуск. Модели задаются в `providers`: у каждой есть `title` и `aliases`, по которым её узнают голосом; можно добавить несколько моделей одного провайдера. Базовый промпт с правилами для озвучки задаётся полем `system_prompt` (пустое значение = встроенный), голосовой промпт добавляется к нему.

</details>

## 🎤 Голосовые команды

Главные: **«Алиса, новый чат»**, **«Алиса, спроси …»**, **«Алиса, продолжить чат …»** и **«хватит»**.

<details>
<summary>📋 Все команды</summary>

| Команда | Что делает |
| --- | --- |
| «Алиса, новый чат» / «новый чат *название*» | Создаёт и сохраняет чат. Без названия имя придумывается по первому вопросу |
| «Алиса, спроси *вопрос*» / «спроси *модель* *вопрос*» | Сразу задаёт вопрос модели по умолчанию или названной («спроси клода …»), в новом сохраняемом чате; дальше разговор продолжается без команд. Также «спроси нейросеть …», «задай вопрос нейросети …», «спроси ИИ …» |
| «Алиса, продолжить чат *название*» | Ищет сохранённый чат по названию (терпимо к окончаниям и ошибкам распознавания) |
| «Алиса, поговорить» | Временный чат, не сохраняется |
| «Алиса, забудь чат *название*» | Удаляет чат (файл уходит в `chats/trash`) |
| «Алиса, список чатов» | Называет сохранённые чаты |
| «хватит», «закрой чат» | Выход из чата; также через 10 минут тишины |
| «Алиса, переключись на клод» / «выбери модель дипсик» | Выбирает модель по названию или псевдониму из `providers` |
| «Алиса, какая модель» | Называет текущую модель и список доступных |
| «Алиса, системный промпт *текст*» / «новая роль *текст*» | Добавляет свои указания к системному промпту |
| «Алиса, какой системный промпт» / «сбрось системный промпт» | Показывает или убирает свои указания |
| «Алиса, выключи интернет» / «включи интернет» | Запрещает или разрешает нейросетям искать в интернете |
| «Алиса, запомни, что *факт*» | Добавляет факт в общую память, его увидят все чаты |
| «Алиса, забудь, что *факт*» / «забудь всё обо мне» | Удаляет похожий факт или всю память |
| «Алиса, что ты обо мне знаешь» | Перечисляет запомненное |
| «Алиса, выключи память» / «выключи запоминание» | Выключает память целиком или только запоминание моделью (и «включи …») |

Пока чат открыт, Алиса слушает дальше без слова «Алиса», и всё сказанное уходит в нейросеть. Вне чата все запросы идут в Яндекс без изменений.

Яндекс по умолчанию маскирует мат при распознавании («х**»). Пока чат открыт, AIBox просит распознавание без маски (флаг `DisableAntimat` в запросе прошивки); обычные запросы к Алисе не меняются. Отключается `"keep_antimat": true` в конфиге.

</details>

<details>
<summary>✏️ Свои фразы для команд</summary>

Фразы команд можно дополнить или заменить в конфиге, полем `commands`, или в веб-панели, в разделе «Голосовые команды» (панель сохраняет в `state.json` и важнее конфига; пустое поле возвращает фразы из конфига). Без поля `commands` всё работает как раньше.

```json
"commands": {
  "temporary_chat": ["поболтаем"],
  "quick": {"add": ["узнай у нейросети"], "replace": true},
  "stop": {"add": ["умолкни"]}
}
```

Список фраз добавляется к стандартным; `"replace": true` отключает стандартные, а без своих фраз выключает команду. Фразы сравниваются без регистра и знаков препинания. После фразы команды с названием или вопросом ждут продолжения: «узнай у нейросети, почему небо голубое», «узнай у нейросети клод …». Команды: `quick` (спроси), `new_chat`, `continue_chat`, `temporary_chat` (поговорить), `forget_chat`, `list_chats`, `exit` (выход из чата), `stop` (перебить ответ), `remember`, `forget_fact`, `forget_all`, `show_memory`, `memory_on`, `memory_off`, `auto_memory_on`, `auto_memory_off`, `which_model`, `model`, `model_switch`, `set_prompt`, `reset_prompt`, `show_prompt`, `search_on`, `search_off`. Неизвестная команда или пустая фраза в конфиге — ошибка `--check-config`.

Слово активации «Алиса» распознаёт сама прошивка, ещё до AIBox, поэтому его не заменить: в приложении «Дом с Алисой» можно выбрать только «Алиса» или «Яндекс». Оба варианта AIBox понимает.

</details>

## 🧠 Общая память

Модель помнит факты о вас во всех чатах: скажите «Алиса, запомни, что …» или просто расскажите о себе, и она запомнит сама.

<details>
<summary>Подробнее о памяти</summary>

Короткие факты о вас («меня зовут Валерий», «отвечай короче», «у меня кот Барсик») хранятся в `/data/opt/aibox/memory.json`, не больше 50 штук, и добавляются в системный промпт каждого чата и быстрого вопроса. Факт попадает в память двумя путями: командой «запомни, что …» или от самой модели. Модель получает правило: если вы рассказали о себе что-то устойчивое, она говорит «запомнила» и ставит в конце ответа служебную пометку `[запомнить: …]`. AIBox вырезает пометку до озвучки и сохраняет факт. Это работает с любой моделью, вызов функций не нужен. Пароли, номера карт и документов и точный адрес модель запоминать не должна.

Во временном чате («поговорить») факты видны, но новые не сохраняются. Пока память выключена, «запомни …» и «забудь, что …» снова уходят Алисе. В веб-панели, в разделе «Память», можно смотреть, править, добавлять и удалять факты, отключить запоминание моделью и запретить отправку памяти отдельным провайдерам.

</details>

## 🌐 Интернет

Модель сама решает, когда ей нужен свежий ответ (новости, погода, курсы, расписания), ищет и пересказывает найденное голосом. Работает с любой моделью, которая умеет вызывать функции, включая DeepSeek.

<details>
<summary>Подробнее о поиске</summary>

Нейросеть может искать в интернете, когда вопросу нужны свежие данные: новости, погода, курсы, расписания. Как в приложении ChatGPT, модель сама решает, что ей нужен поиск: она вызывает инструмент `web_search` (tool calling), AIBox передаёт запрос поисковику, а ответ модель пересказывает голосом. Так ищет любая модель с вызовом функций, включая DeepSeek.

Поисковики выбираются в веб-панели по порядку, до трёх: если первый не ответил за 20 секунд или с ошибкой, спрашивается следующий.

- **Поисковая модель** — любая модель со своим поиском: Perplexity Sonar (свой API `https://api.perplexity.ai` или `perplexity/sonar` в OpenRouter, ищет на каждый запрос), модели OpenRouter с `:online`, OpenAI (Responses API с `web_search`), Claude (инструмент `web_search`), OpenRouter (плагин `web`). Она получает запрос и излагает найденные факты в нескольких предложениях.
- **Свой API только для поиска** — при добавлении своего API в панели отметьте «Только для поиска в интернете». Такой провайдер не отвечает в чатах и не выбирается голосом, а только ищет по просьбе основной модели; AIBox спрашивает его как есть, так что модель должна уметь искать сама. Первый такой провайдер сразу становится поисковиком. Поисковиком можно выбрать и любую другую модель.
- **Tavily** — поисковый API, отдаёт 3–4 коротких выдержки. Нужен ключ `TAVILY_API_KEY`. Используется по умолчанию, пока порядок не задан.

Модель со своим поиском может искать и сама, без посредника. Способ выбирается для каждой модели (`auto`, `tool`, `native`, `off`). В режиме `auto` модель ищет через поисковики, если какой-то из них готов, иначе своим поиском, если он у неё есть; Sonar всегда ищет сам. Остальные «OpenAI-совместимые» API, например DeepSeek, своего поиска не имеют. Ссылки и сноски из ответа вырезаются, чтобы их не зачитывать. Поиск включается только в чатах, служебные запросы (название чата) идут без него. Настройки Tavily в конфиге: `"search": {"provider": "tavily", "api_key_env": "TAVILY_API_KEY", "max_results": 4}`.

</details>

## 💻 Веб-панель

`http://<ip колонки>:8100` — панель работает в том же процессе AIBox, доступна в локальной сети без пароля и позволяет выбрать провайдера и конкретную модель (кнопка «Загрузить список» спрашивает модели у провайдера), задать свой промпт и базовые правила, вписать ключи. Там же можно добавить свой API: OpenAI-совместимый (Groq, Together, Mistral, Ollama или LM Studio в локальной сети и т. п.) или Anthropic. Указываются название, адрес до `/v1`, модель, ключ и имена для голоса; такой провайдер хранится в `state.json`, его ключ в `secrets.env` как `AIBOX_KEY_API_N`. Изменения применяются без перезапуска. Отключается полем `web.enabled` в конфиге.

## 🔧 Как это работает

Прошивка Станции общается с облаком Алисы по WebSocket (`uniproxy`). AIBox ставится между ними на `127.0.0.1:8443`: в `quasar.cfg` адрес `uniProxyUrl` меняется на `ws://127.0.0.1:8443/uni.ws`. Распознавание речи и синтез голоса остаются у Яндекса, поэтому ответы нейросети звучат голосом Алисы. Протокольная часть взята из [quasar-bridge](https://github.com/skrashevich/quasar-bridge).

```text
🎙️ Станция ──► AIBox (127.0.0.1:8443) ──► uniproxy Яндекса (речь ⇄ текст, голос)
                    │
                    └──► DeepSeek / Claude / ChatGPT / OpenRouter / свой API
```

## ⚠️ Риски

- 🔇 Если AIBox не запущен, а адрес переключён, Алиса не отвечает совсем: используйте `aiboxctl.sh rollback`.
- 🔄 Обновление прошивки может перезаписать `quasar.cfg` или изменить протокол.
- 🔐 Речь по-прежнему обрабатывает Яндекс, а текст вопросов уходит выбранному провайдеру.

## 📜 Правовая информация
